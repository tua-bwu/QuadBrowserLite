# QuadBrowserLite

1つのウィンドウに4画面を並べる、低機能なブラウザです。
無料・非ログインで使える AI サービスを並べて、作業に没頭するためのものです。

## 特徴と割り切り

- 4画面を同時に表示します。
- プライベートウィンドウ (InPrivate) で動きます。ログイン情報や閲覧データは残さない前提です。
- 終了時に一時データを削除します。消し残しは次の起動時に削除します。
- 自分用の道具です。機能は少なく、`.lst` の書き間違いなどは自分で直してください。

プライベートウィンドウは匿名化ではありません。入力した内容は各サービスに送られます。
ダウンロードしたファイルや、`.lst` に保存した名前と URL は残ります。

## 動かすのに必要なもの

- Windows (x64)
- .NET 8 デスクトップ ランタイム
- Microsoft Edge WebView2 ランタイム

## かんたんヘルプ

### 画面の操作

- 仕切り線をドラッグすると、画面の大きさを変えられます。中央の交点は、上下左右を同時に動かせます。
- 別ウィンドウが開いたまま本体を閉じると、確認が出ます。

### タイトルバー右クリックのメニュー

| 項目 | 内容 |
|---|---|
| 更新 | 選んだ画面を、設定の URL で開き直します |
| 設定... | 設定画面を開きます |

起動直後は「(起動待ち)」と表示され、準備が終わると使えます。

### 設定画面

| 操作 | 内容 |
|---|---|
| 各画面の一覧 | 表示するサービスを選びます |
| 名前・URL と「登録」 | 一覧に追加します。同じ名前は確認して上書きします |
| 4画面に反映 | 選んだ内容を今の画面に反映します |
| この配置で次回も起動 | 選んだ4つを、次回の起動時の設定として保存します |

「登録」と「この配置で次回も起動」は、すぐに保存されます。「キャンセル」では戻りません。

### 削除や並べ替え

画面からはできません。ただのテキストファイルなので、自分で編集してください。

設定は、実行ファイルと同じ場所の `QuadBrowserLite.lst` (UTF-8) にあります。
アプリを終了してから編集してください。

```
[panes]
pane0,ChatGPT

[urls]
ChatGPT,https://chatgpt.com/
```

- `[urls]` : `名前,URL` を1行ずつ書きます。削除は、その行を消します。
- `[panes]` : `pane0` 左上、`pane1` 右上、`pane2` 左下、`pane3` 右下。値は `[urls]` の名前です。
- 消した名前を `[panes]` で使っていると、その画面は空白になります。

### 新しい版に入れ替えるとき

配布物には初期状態の `QuadBrowserLite.lst` が入っています。
自分の `.lst` は上書きしないでください。
