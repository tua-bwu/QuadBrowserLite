# QuadBrowserLite

4つのブラウザ画面を、ひとつのウィンドウに並べて使うための小さなツールです。

ChatGPT などの AI サービスを並べて、あちこちウィンドウを切り替えずに作業できるようにしました。
自分で使うために作ったものなので、機能は必要なものに絞っています。

## こんなことができます

- 画面を4つ並べて、同時に表示できます。
- 仕切り線を動かして、画面の広さを調整できます。
- それぞれの画面で、別のサービスやページを開けます。
- 設定から、使いたいサービスや URL を登録できます。
- InPrivate モードで動作し、終了時には一時データを削除します。

ちょっとした注意点もあります。
InPrivate は匿名化する機能ではありません。入力した内容は各サービスに送信されます。また、ダウンロードしたファイルや、設定ファイル（.lst）に書いた名前・URLは残ります。

## 使うために必要なもの

- Windows (x64)
- .NET 8 デスクトップ ランタイム
- Microsoft Edge WebView2 ランタイム

## 使い方

### 画面の調整
画面の境目をドラッグすると、上下・左右の大きさを変えられます。
中央の交点を動かせば、4画面をまとめて調整できます。

リンクなどから別ウィンドウが開くこともあります。
別ウィンドウを開いたまま本体を閉じようとすると、確認メッセージが表示されます。

### タイトルバーのメニュー
ウィンドウ上部のタイトルバーを右クリックすると、メニューが開きます。

| 項目 | できること |
|---|---|
| 更新 | 選んだ画面を、設定されている URL で開き直します |
| 設定... | 表示するサービスや URL を設定します |

起動直後は準備のため、メニューに「起動待ち」と表示されます。画面の準備が終わると使えるようになります。

### サービスや URL の設定
設定画面では、各画面に表示するサービスを選べます。

| 操作 | 内容 |
|---|---|
| サービス一覧 | 表示したいサービスを選びます |
| 名前・URL と「登録」 | 新しいサービスを一覧に追加します |
| 4画面に反映 | 選んだ内容を、現在の画面に反映します |
| この配置で次回も起動 | 今の4画面の組み合わせを、次回起動時にも使います |

「登録」と「この配置で次回も起動」は、操作した時点で保存されます。そのため、あとから「キャンセル」を押しても、保存済みの内容は元に戻りません。

## 設定ファイルを直接編集する場合

サービスの削除や並べ替えは、設定画面からはできません。
その場合は、実行ファイルと同じ場所にある `QuadBrowserLite.lst` を編集してください。文字コードは UTF-8 です。編集するときは、先にアプリを終了してください。

ファイルは、たとえば次のような形式です。

```
[panes]
pane0,ChatGPT

[urls]
ChatGPT,https://chatgpt.com/
```

- `[urls]` には、`名前,URL` の形式でサービスを1行ずつ書きます。削除するときは、その行を消します。
- `[panes]` は画面ごとの設定です。pane0 は左上、pane1 は右上、pane2 は左下、pane3 は右下です。
- `[panes]` に書いた名前が `[urls]` に見つからない場合、その画面は空白になります。

## 新しいバージョンに入れ替えるとき

新しい配布物には、初期状態の `QuadBrowserLite.lst` が含まれています。
すでに自分の設定を使っている場合は、そのファイルを上書きせず、今までの `.lst` を引き続き使ってください。

各 AI サービスの利用については、それぞれのサービスの利用規約に従ってください。ログインなしで利用できるかどうかも、サービス側の変更によって変わることがあります。
