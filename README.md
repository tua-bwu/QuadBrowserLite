# QuadBrowserLite

4つのWebブラウザを、ひとつのウィンドウに。

QuadBrowserLiteは、4つのWebブラウザを2×2のレイアウトで同時に表示する、Windows向けの軽量マルチブラウザアプリケーションです。

メインウィンドウは常に4つのブラウザ画面で構成され、それぞれ独立してWebページを表示します。各画面には異なるURLを設定できるため、複数のWebサイトをひとつのウィンドウ内に並べて閲覧できます。

画面のレイアウトは自由に調整可能です。中央の仕切りをドラッグすることで、上下左右の表示領域を変更でき、閲覧するコンテンツに合わせた画面構成が可能です。中央の交点をドラッグすれば、4画面をまとめて調整することもできます。

各ブラウザのURLは個別に設定でき、登録済みのプリセットから選択します。新しいURLは設定画面からプリセットに追加できます。

一般的なWebブラウザにあるアドレスバーやお気に入り機能は備えていません。URLの変更は設定画面から行う設計のため、URLを頻繁に切り替える用途には向いていません。

## 独立した4つのブラウザ環境

QuadBrowserLiteでは、4つのブラウザそれぞれに独立したユーザーデータ環境を割り当てています。

Cookie、キャッシュ、ローカルストレージなどのブラウザデータは相互に共有されず、ログイン状態やサイトごとの保存データもそれぞれ独立して管理されます。

そのため、4つのブラウザで同じWebサービスを開いた場合でも、それぞれ別のブラウザ環境として利用できます。異なるアカウントでのログインや、ブラウザごとに異なるサイト設定の管理にも対応します。

また、各ブラウザのユーザーデータには一時フォルダーを使用します。アプリケーションの終了時にはブラウザを破棄し、一時データの削除を試みます。次回起動時には新しいブラウジング環境を用意する設計です。

なお、本アプリケーションは匿名通信や身元秘匿を目的としたものではありません。一般的なブラウザのプライベートブラウジング機能と同様、ローカルに保存されるブラウザデータを抑制するためのものであり、アクセス先のWebサイトやネットワーク管理者などから利用者を匿名化する機能はありません。

ダウンロードしたファイルや、設定ファイル（.lst）に記載したサービス名・URLは、アプリケーション終了後も残ります。

## 主な特徴

- 4つのブラウザ画面を常時表示する2×2レイアウト
- 各ブラウザで異なるWebページを独立して表示
- ブラウザごとの個別URL設定
- URLはプリセット選択のみ
- プリセットに追加は可能
- ドラッグ操作による表示領域の自由な調整
- 中央の交点をドラッグして4画面をまとめて調整
- 標準の全画面表示も、各ブラウザの枠内に表示
- 4つのブラウザ間でCookieやブラウザデータを共有しない独立環境
- ブラウザごとに独立したログイン状態・保存データを管理
- ブラウザごとに一時ユーザーデータフォルダーを使用
- アプリケーション終了時のブラウザ破棄と一時データ削除処理
- 次回起動時に新しいブラウジング環境を用意
- 別ウィンドウを開いたまま本体を終了しようとした場合の確認表示

## 使うために必要なもの

- Windows（x64）
- .NET 10 デスクトップ ランタイム
- Microsoft Edge WebView2 ランタイム

## 使い方

### 画面の調整

画面の境目をドラッグすると、上下・左右の大きさを変えられます。

中央の交点を動かせば、4画面をまとめて調整できます。

リンクなどから別ウィンドウが開くこともあります。
別ウィンドウを開いたまま本体を閉じようとすると、確認メッセージが表示されます。

### タイトルバーのメニュー

ウィンドウ上部のタイトルバーを右クリックすると、メニューが開きます。

|項目 |できること                   |
|---|------------------------|
|更新 |選んだ画面を、設定されているURLで開き直します|
|設定…|表示するサービスやURLを設定します      |

起動直後は準備のため、メニューに「起動待ち」と表示されます。画面の準備が終わると使えるようになります。

### サービスやURLの設定

設定画面では、各画面に表示するサービスを選べます。

|操作         |内容                      |
|-----------|------------------------|
|サービス一覧     |表示したいサービスを選びます          |
|名前・URLと「登録」|新しいサービスを一覧に追加します        |
|4画面に反映     |選んだ内容を、現在の画面に反映します      |
|この配置で次回も起動 |今の4画面の組み合わせを、次回起動時にも使います|

「登録」と「この配置で次回も起動」は、操作した時点で保存されます。そのため、あとから「キャンセル」を押しても、保存済みの内容は元に戻りません。

## 設定ファイルを直接編集する場合

サービスの削除や並べ替えは、設定画面からはできません。

その場合は、実行ファイルと同じ場所にある `QuadBrowserLite.lst` を編集してください。文字コードはUTF-8です。編集するときは、先にアプリを終了してください。

ファイルは、たとえば次のような形式です。

```ini
[panes]
pane0,ChatGPT

[urls]
ChatGPT,https://chatgpt.com/
```

- `[urls]` には、`名前,URL` の形式でサービスを1行ずつ書きます。削除するときは、その行を消します。
- `[panes]` は画面ごとの設定です。pane0は左上、pane1は右上、pane2は左下、pane3は右下です。
- `[panes]` に書いた名前が `[urls]` に見つからない場合、その画面は空白になります。

## 新しいバージョンに入れ替えるとき

新しい配布物には、初期状態の `QuadBrowserLite.lst` が含まれています。

すでに自分の設定を使っている場合は、そのファイルを上書きせず、今までの `.lst` を引き続き使ってください。
